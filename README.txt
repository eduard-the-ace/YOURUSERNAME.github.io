ACADEMIC PORTFOLIO - QUICK START

1. Open index.html in your browser.
2. Edit content in index.html, research.html, publications.html, presentations.html, activities.html, and kids.html.
3. Edit colors in style.css. Main green is --forest:#10452e.
4. Add your own photo: save a photo as profile.jpg in this folder, then replace the portrait image src URL in index.html with profile.jpg. The Google Sites image link may require sign-in; initials ET appear if it fails.
5. Publications are rendered in publications.html. publications.json is a separate editable data copy, but changes to JSON alone do not update the webpage.
6. To publish: create a public GitHub repository called YOURUSERNAME.github.io, upload all website files into the repository root, then Settings > Pages > Deploy from branch > main > /(root).
7. Website: https://YOURUSERNAME.github.io

NOTE: Presentations and Activities are placeholders, not factual listings. Kids problems are original examples.
